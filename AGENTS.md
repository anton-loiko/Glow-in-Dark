## Доступные инструменты (MCP Серверы)

Ты ОБЯЗАН использовать эти подключенные MCP-серверы для выполнения соответствующих задач:

- **godot-core**: Управление движком. Используй системную команду `godot` для запуска игры, отладки сцен и взаимодействия с деревом узлов.
- **godot-docs**: База знаний. Всегда запрашивай документацию через этот сервер, если не уверен в синтаксисе Godot 4 или актуальных методах API, чтобы избежать галлюцинаций.
- **aseprite**: Растровая графика мира (Hi-Res 2D, не пиксель-арт). Используй для создания и экспорта спрайтов, normal map, масок и анимаций (см. `docs/GRAPHICS.md`).
- **inkscape**: Векторная графика. Используй для создания UI-элементов, иконок и векторных пропсов в формате SVG/PNG.
- **ios-simulator / android-emulator**: Мобильное тестирование. Используй для установки собранных билдов, снятия скриншотов экрана и проверки интерфейса тапами.
