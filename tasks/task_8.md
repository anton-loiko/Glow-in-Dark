# Task 8 · Арт-пайплайн, аудио и хаптика, производительность, QA и релиз

## Обоснование

Legacy-ассеты — сборные паки Kenney (`kenney_game_icons`, `kenney_roguelike_modern_city`, `modern_rpg_icon_pack`, пиксельный шрифт), 8 фортепианных треков и 7 UI-звуков Kenney, спрайт героя 16×16. Art Direction Reboot выносит вердикт «Биолюминесцентный нуар»: hi-res 2D-спрайты (герой ~80–90pt вместо ~24px) с normal map, реальный `PointLight2D`, `LightOccluder2D`, bloom. Design System §06 задаёт хаптику и звук по событиям, §08 — перф-бюджет 60 FPS на Redmi 9 / iPhone 8 (эталон iOS заменён на iPhone XR — D16) и доступность.

Эпик собирает всё, что «не код систем», но без чего V1 не выйдет: производственные спеки ассетов, аудио-/хаптик-слой, перф-бюджеты с замером, тестовую инфраструктуру и релизный чек-лист. Решение принято: **Hi-Res 2D + normal maps** (см. `docs/GRAPHICS.md`).

## Чеклист реализации

### 1. Спецификация ассетов (`docs/asset_specs.md`)
- [ ] **Огонёк:** капля с белым раскалённым ядром и двумя большими глазами; 3 состояния (база · HP < 25% · поздний забег «Сверхновая» — слои ауры/орбит/пламени на макушке), 4 эмоции глаз; дыхание и squash & stretch — движком. Альбедо + normal map, исходник 2× от экранного.
- [ ] **Враги:** по Enemy DS §09 — 2× экранного (S 72, M 128, L 224, XL 320px), атлас на архетип: альбедо + normal + маска (R глаза, G трещины); покадрово только idle/move, telegraph, attack.
- [ ] **Мир:** на биом 3–4 варианта плитки пола (приглушённая насыщенность), пропсы с normal map + полигоны `LightOccluder2D`, биолюминесценция (грибы, светлячки, руны) — не красная и не янтарная, окружение ≤ 60% яркости врагов в свете. Биомы: Затопленный город, Спящий лес, Ржавый порт.
- [ ] **Маяк:** 5 спрайтов пьедестала + 4 варианта кристалла (24 кадра вращения) на главу, диорама хаба с кварталами под маску `hub_light`.
- [ ] **Гир:** иконки предметов (на слот × базовые предметы), рамки `gear_frame_{rarity}.png` 96×96 9-slice, `gear_glow.png`, сундуки (Базовый — дерево/железо с янтарным швом; Премиум — тёмный кристалл с голубым неоном).
- [ ] **UI-иконки:** hi-res на сетке 24pt, мягкие формы, заливка + внутренний тёплый блик, без контура, SVG белым/серым под `modulate`; иконки навыков — мастер 16×16 (тест силуэта в грейскейле) → финал 128px.
- [ ] **Бренд:** знак (капля в тайле `ink.900`, r 28%), горизонтальный локап, варианты (основной / моно / на янтаре / инверсия), мин. размеры 64/44/24; иконка приложения 1024 (Огонёк с лицом, 40% ширины, центр 52% Y, пара красных глаз в левом верхнем углу; глаза убираются ниже 80px; тест в грейскейле); сплэш 1080×1920 по DS §07.
- [ ] Чек-лист ревью ассета: силуэт в грейскейле, цветовые законы (тепло = жизнь, красный = угроза, голубой = деньги), бюджет glow.

### 2. Рендер и шейдеры
- [ ] `CanvasTexture` (diffuse + normal) для всех освещаемых спрайтов; `PointLight2D` с тенями только у игрока (и Маяка в хабе).
- [ ] Бюджет света в бою: 1 `PointLight2D` игрока + до 6 доп. источников (топливо, взрывы, сферы, след) — менеджер `LightBudget` отклоняет лишние (понижает приоритетом).
- [ ] Bloom: один проход в половинном разрешении (`WorldEnvironment` glow); уровни `glow_hdr_threshold` под луч Маяка 0.7.
- [ ] Шейдеры: rim + dissolve врагов, глаза unshaded, кольцо жара Ауры, ударная волна с дисторсией, языки пламени, hex-пузырь Щита, иней, виньетка, blur/dim модалов, блик легендарного, туман с параллаксом 0.8×.
- [ ] Прекомпиляция шейдеров (прогрев на сплэше), чтобы не было фризов при первом Взрыве Света.

### 3. Аудио (DS §06)
- [ ] Пул SFX-плееров (≈ 24 `AudioStreamPlayer`), лимит одновременных одинаковых звуков, приоритеты.
- [ ] События → звуки: подбор искры «дзынь» +1 полутон за искру в серии (окно 400 мс, до +12) · Топливо/Взрыв «вдох → низкий бум + блестящий хвост» · сожжён враг короткое «пшш» (высота по размеру) · урон — глухой удар + искажение музыки 200 мс · HP < 25% — low-pass музыки + дыхание · левел-ап — мажорный аккорд + «флип» · Маяк — восходящее глиссандо, хор + колокол · покупка — уникальный «хрустальный» аккорд (только IAP) · кнопка — мягкий клик, Disabled — глухой «тук» · враги E1/E3/E5/E7 · Гаситель — нарастающий гул 1.2 с.
- [ ] Музыка: базовый луп + слой ударных на фазе Напряжения + разрешение аккордом на Награде (адаптивная музыка через `AudioStreamInteractive`/`AudioStreamSynchronized`); тема хаба; смена музыки на вехах Маяка.
- [ ] −60% музыки во время RV, стоп при сворачивании.

### 4. Хаптика `FeedbackManager` (DS §06)
- [ ] Маппинг: искра `selection` ≤ 1/80 мс · топливо `heavy` · сожжён враг `light` ≤ 1/120 мс · урон `rigid` (Щит → `soft`) · HP < 25% `soft` каждые 1.2 с · левел-ап `success`, выбор карты `medium` · Маяк — `light` ticks с растущей частотой, веха `success + heavy` · покупка `success` · кнопка `selection`, Disabled `rigid`.
- [ ] iOS: `UIImpactFeedbackGenerator`/`UISelectionFeedbackGenerator`/`UINotificationFeedbackGenerator` через плагин; Android: `VibrationEffect` предустановки / `Input.vibrate_handheld(duration_ms, amplitude)` как фолбэк.
- [ ] Не срабатывает при выключенном тоггле «Вибрация» и в системном режиме энергосбережения.

### 5. Производительность
- [ ] Целевые устройства: Redmi 9 (Android), iPhone XR (iOS, минимальная iOS 17 — D16) — 60 FPS.
- [ ] Бюджеты: враги ≤ 5 мс CPU при 150 активных; ≤ 3 draw call на архетип (MultiMesh); без `instantiate` в бою; GC-спайки = 0 (пулы); первый кадр забега после прогрева < 1 с.
- [ ] `PerfOverlay` (debug): FPS, frame time, draw calls, активные враги/искры/цифры, занятость пулов, мс систем (`LightDamageSystem`, `WaveDirector`, `SeparationGrid`).
- [ ] Стресс-сценарий: 10-минутный забег-бот с засадами и 150 врагами; отчёт FPS p1/p50 в CI-артефакт (ручной прогон на устройстве перед релизом).
- [ ] Текстуры: VRAM-сжатие ETC2/ASTC (уже включено), атласы, mipmaps выкл. для UI.
