# Task 2 · Core Gameplay: Огонёк, Свет/Топливо, мир из чанков, цикл забега

## Статус (2026-09-25)

Реализовано ядро забега: `Player` (+`PlayerLight`, `PlayerVisual`, `LightBurst`), `RunCamera`, `PickupSystem`,
`ChunkStreamer`/`Chunk`, `ChapterEnvironment`, `RunDirector`, сцена `RunScene` (S05), временный `RunHUD`
с HP-виньеткой, `FloatingJoystick`. Проверки: 58 скриптов в строгом режиме, 44 юнит-теста, сквозной прогон
забега (движение, левел-ап → S06, топливо → Взрыв Света, смерть → S08 → воскрешение за рекламу → смерть → S09)
и визуальная проверка в окне редактора через MCP (свет, тени пропсов, джойстик).

Отличия от плана:
- Джойстик — свой `FloatingJoystick` вместо встроенного `VirtualJoystick` Godot 4.7: встроенный не даёт исчезновение
  за 150 мс, и его ввод нельзя проверить автотестом. Свой — ~100 строк, `_input` + `make_input_local`, touch и мышь.
- Графика временная, процедурная (капля, пропсы-прямоугольники, точки биолюминесценции) до hi-res арта из task_8.
  Свет мира — тёплый белый в оттенке скина (чистый янтарь по холодному полу давал «олив»), сам Огонёк — цвета скина.
- Воскрешение: `GameManager.request_revive(source)` (реклама/30 ◆, один раз за забег) → факт `EventBus.player_revived`
  → `RunDirector` применяет эффект. UI не касается узлов игры.
- Искры и топливо пока даёт временный спавнер (`balance.run.debug_pickup_spawner`); источники из врагов и фаз волн — task_3.
- Не сделано до task_3/task_8: оглушение врагов Взрывом (есть факт `light_burst_triggered`), туман, реакция на фазы,
  навигация врагов, эмоция «сосредоточен».

## Обоснование

Текущий забег — «спуск вниз» по чанкам 270×480 до объекта `Exit`, свет — нормированное число 0..1 с HP-полоской в HUD, ввод с клавиатуры (`ui_left/right`), левел-ап каждые 3 искры. Дизайн-система описывает другой продукт:
- **Свет = HP = оружие = обзор**: радиус света по умолчанию 55% ширины экрана, тело Огонька 7–8% ширины (≈80–90pt), камера держит Огонька по центру X и на 51% Y (DS S05, Art Direction §02).
- Забег — **выживание по таймеру главы 10:00** (Enemy DS §05), конец — S09 «Глава пройдена»; смерть → S08 → S09.
- Топливо запускает **Взрыв Света** — главный дофаминовый момент с таймингами до миллисекунды.
- Искры — это одновременно опыт и валюта; XP-полоса отдельна от счётчика.

Эпик переписывает `Player`, мир и поток забега, опираясь на `RunContext`, `StatBlock`, `EventBus`, `TimeService`, пулы из task_1.

## Чеклист реализации

### 1. Модель света `PlayerLight`
- [x] Хранит `current: float`, `max_value: float` (из `StatBlock.max_light`); радиус в пикселях = `current × px_per_light` (калибровка: полный свет базового Огонька = 55% ширины экрана → радиус ≈ 107pt при ширине 390).
- [x] `decay_rate` (мягкий таймер, GDD 3.1) — медленное затухание; значения в `balance.json` (`player.decay_per_s`), модификаторы Маяка/Ядра/скина через `StatBlock`.
- [x] `apply_damage(amount_pct_of_max: float, source: StringName) -> float` — урон касания в % от максимума (Enemy DS §03), с `contact_damage_mult` (Щит, Ядро, Призрачный). Возвращает фактический урон, эмитит `EventBus.player_damaged`.
- [x] `heal(amount: float)` с учётом `fuel_efficiency`; `set_max(value, animate := true)` — плавное расширение за 500 мс `ease.settle` (Энергоёмкость).
- [x] Неуязвимость `grant_invulnerability(seconds)` (1.5 с после левел-апа — Skills DS L8; 2 с после revive — DS S08).
- [x] «Последний шанс» (Энергоёмкость ур.5) — хук `on_lethal_hit` для навыка (task_4).
- [x] При `current <= 0` → `EventBus.player_light_depleted` ровно один раз.
- [x] Эмит `player_light_changed(current, max)` не чаще раза в кадр и только при изменении.

### 2. Контроллер Огонька `Player`
- [x] `CharacterBody2D`, `motion_mode = FLOATING`; скорость `StatBlock.move_speed` (база 110 pt/с), ускорение/трение из конфига.
- [x] Ввод только через `FloatingJoystickInput.get_vector()`: джойстик 96pt появляется в точке касания в **нижних 60% экрана**, исчезает за 150 мс при отпускании (DS S05). Мёртвая зона и радиус — в конфиге. Касание в верхних 40% не создаёт джойстик.
- [x] FSM `IDLE / MOVE / HURT / DEAD / REVIVING` (enum + `match`), без `_process` в DEAD.
- [x] Коллизии: слой `player`, маска `world|enemy|pickup`. Хитбокс тела — `CircleShape2D`.
- [x] `PointLight2D` игрока — единственный постоянный свет в бою (бюджет DS §08: 1 свет игрока + до 6 источников); `texture_scale` от радиуса, цвет = `SkinDef.light_color`.
- [x] Area2D `LightArea` (слой `player_light_area`) с `CircleShape2D` радиуса света — враги определяют «в свете» через неё, а не через расстояние в каждом враге (замена `_handle_light_burn` в `BaseEnemy`).

### 3. Визуал и «сочность» `PlayerVisual` (GDD 7.2, Art Direction §02)
- [x] Дыхание: `t.breath` 1.2 с, scale 1 → 1.04, яркость ±10% (`ease.glow` sine in-out) — таймер общий с Ember «В БОЙ» и Маяком (глобальный `BreathClock` в `TimeService`).
- [x] Squash & stretch по скорости; +4% stretch за уровень Ускорения (task_4 передаёт множитель).
- [ ] Эмоции глаз (4): спокоен / сосредоточен (враги в свете) / испуган (HP < 25%) / счастлив (левел-ап). _Сделано процедурно (`PlayerVisual.Mood`); «сосредоточен» включается, когда появятся враги (task_3); кадры атласа — с hi-res артом (task_8)._
- [x] Шлейф из тлеющих частиц (`GPUParticles2D`, цвет скина).
- [x] HP < 25%: цвет остывает к `cold #8FA3C0`, рваное мерцание, «сердцебиение» раз в 1.2 с (эмит события для HUD-виньетки и хаптики `soft`).
- [x] Получение урона: радиус света −N с упругим откатом 120 мс, Огонёк моргает (DS §05).

### 4. Взрыв Света `LightBurst` (DS §05, Art Direction VFX)
- [x] Последовательность по таймингам: hit-stop 60 мс (`TimeService.hit_stop`) → сжатие 60 мс → белый кадр 2 фрейма + тряска 6pt/180 мс → кольцо ударной волны 250 мс (шейдер дисторсии, отбрасывание и оглушение врагов 600 мс) → радиус света с overshoot 8% к 500 мс → пепел и магнит искр к 900 мс.
- [x] Режим «Без белых вспышек» (`settings.no_flashes` или системный Reduce Motion): янтарь 40% вместо белого, тряска 3pt; не больше 3 вспышек в секунду — подряд идущие взрывы склеиваются (WCAG 2.3.1, DS §08).
- [x] Вызывается из: подбор Топлива, revive (без урона по игроку), навык «Сверхновая»/Перезарядка ур.5 (task_4). Эмит `EventBus.light_burst_triggered`.

### 5. Пикапы
- [x] `SparkPickup` (пул 300): номинал; отскок 12–30pt при дропе, через 150 мс летит к магниту; без магнита лежит и мерцает 20 с, затем исчезает. Если искр на полу > 60 — сливаются в одну крупную (номинал ×5) (Enemy DS §07).
- [x] `PickupMagnet` на игроке: базовый радиус 60pt × `StatBlock.magnet_radius`; попавшие в радиус пикапы летят к игроку (скорость из конфига). Визуальный хвост/спираль — хук для навыка Магнит (task_4).
- [x] Подбор искры → `RunContext.run_sparks += n × spark_income_mult`, `xp += n`; эмит `run_sparks_changed`, `xp_changed`; звук «дзынь» +1 полутон за искру в серии (окно 400 мс, максимум +12), хаптика `selection` ≤ 1/80 мс.
- [x] `FuelCapsule`: янтарная капсула с glow G2, видна сквозь тьму на 1.5 экрана (unshaded + собственный маленький `PointLight2D`, учесть бюджет 6 источников). Подбор → `PlayerLight.heal` + `LightBurst`.
- [x] `RunChestPickup`: маленький сундук с серым швом (дроп элиты/Гасителя, task_3), летит к Огоньку, иконка висит у счётчика искр; добавляется в `RunContext.run_chests` (открытие — на S09, task_6).

### 6. XP и левел-ап (триггер; UI и выбор — task_4/5)

- [x] При XP ≥ 90% — сигнал для мерцания полосы (Skills DS L1).
- [x] При заполнении → `EventBus.level_up_ready(level, queued)`; поддержка очереди, если одна искра даёт 2 уровня.

- [x] Детерминированный выбор шаблона чанка по `(chunk_x, chunk_y, run.seed)` — возврат к пройденному месту даёт тот же чанк.

- [x] Шаблон чанка (`ChunkTemplate.tscn`): 4 слоя по Art Direction §02 — пол (`TileMapLayer`, 3–4 варианта на биом), пропсы с normal map + `LightOccluder2D`, биолюминесценция (unshaded-спрайты, ориентиры и подсказки к топливу), туман с параллаксом 0.8× (общий слой `RunScene`).

## Критерии приёмки

- [x] В редакторе и на устройстве: Огонёк ≈80–90pt, радиус света ≈55% ширины экрана, камера держит героя на 51% высоты.
