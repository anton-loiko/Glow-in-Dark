# Task 3 · Враги, волны и боевая система (Enemy Design System)

## Статус (2026-09-25)

Реализована логика врагов и волн: `Enemy` (автомат E1–E8 + оглушение/отступление/деспавн, хуки замедления,
заморозки, отбрасывания для task_4), атаки `DashAttack` / `SlamAttack` / `DarkAuraAttack`, `TelegraphMarker` (пул 6),
`EnemyManager` (пулы по архетипам, единый тик, сетка разделения стаи, урон светом тиками 0.25 с, цифры урона
с накоплением 0.4 с, касания, Плазменный/Инферно/Синее Пламя, Взрыв Света → оглушение, Гаситель → −25% HP и
выключение ауры, награды и сундуки забега, раскол Пожирателя), `SpawnRing`, `WaveDirector`.

Проверки: 67 скриптов в строгом режиме, 50 юнит-тестов; бот-забег 10:00 на ускоренном времени —
`chapter_cleared` на 600 с, петля фаз 45/30/15 и финальное напряжение с 9:00 точны, лимиты соблюдены,
0 спавнов в кадре/свете (кроме засады и раскола — по DS), первый левел-ап 25–35 с; визуально в окне —
глаза во тьме, контровая обводка и трещины в свете, цифры урона, дроп искр и топлива.

Не сделано (ждёт task_8 — арт, шейдеры, перф — или решения по балансу):
- normal map + rim-шейдер, dissolve-трещины, угольки и пепел, покадровая анимация, варианты по главам, звуки — сейчас процедурная отрисовка;
- MultiMesh для Шёпотов и LOD вне света; замер ≤ 5 мс CPU на Redmi 9;
- Плакальщик — только данные (выключен флагом, D8);
- плотность волн низкая: пик ~55 врагов при лимите 150 — базовая аура сжигает Шёпотов за ~0.5 с (B4 в README);
- Time to Flow: первый левел-ап 25–35 с в зависимости от движения — граница «≤ 30 с» (B2).

## Обоснование

Сейчас есть один враг `ShadowEnemy`, который **убегает от света** при большом радиусе (противоречит Enemy DS: враги охотятся на игрока), спавнится шансом на маркерах чанка, окрашивается `modulate` в красный/жёлтый (нарушает закон «никакого тёплого» в теле врага), умирает через `queue_free` и `instantiate` искры. Урон светом считается дистанцией в каждом враге каждый кадр.

Enemy DS задаёт: 8 общих состояний E1–E8, 4 архетипа V1 (+1 предложенный), элитный модификатор, директор волн с петлёй ~90 с и таймлайном на 10 минут, лимиты на экране, пулы, LOD вне света и бюджет ≤ 5 мс CPU на Redmi 9. Архитектура: **общая FSM + данные архетипа (`EnemyDef`) + компонент атаки**, чтобы новый враг = «3 клипа + normal map + строка конфига».

## Чеклист реализации

### 1. Данные архетипов `EnemyDef` + `configs/enemies.json`
- [x] Поля: `id`, `size_class (S|M|L|XL)`, `hp`, `speed`, `contact_damage_pct`, `sparks`, `fuel_chance`, `embers`, `hit_stop_ms`, `lethal_number_scale`, `eye_count`, `eye_shape`, `telegraph_ms`, `unlock_time_s`, `screen_limit`, `pool_size`, `knockback_resist`, `attack` (id + параметры).
- [x] Значения V1 (глава 1, минута 0; Enemy DS §03, §07):
  | id | Класс | HP | Скор. | Урон | Искры | Топливо | С | Лимит |
  |---|---|---|---|---|---|---|---|---|
  | whisper (Шёпот) | S 36pt | 10 | 70 | 4% | 1 | 1% | 0:00 | 120 |
  | reaper (Жнец) | M 64pt | 35 | 60 / рывок 320 | 10% | 3 | 4% | 1:30 | 8 |
  | devourer (Пожиратель) | L 112pt | 180 | 35 | 18% | 10 | 20% | 3:00 | 4 |
  | extinguisher (Гаситель) | XL 160pt | 600 | 45 | аура −30% | 40 | 100% ×2 | 5:00 | 1 |
  | mourner (Плакальщик)* | M | 50 | 50 | капля 6% | 4 | 5% | 2:30 | 4 |
  \* вне GDD — только данные за выключенным флагом `enemies.mourner_enabled`, арт не делаем до плейтестов (D8).
- [x] Рост за минуту: HP ×1.18, урон ×1.08, скорость без изменений — `waves.json.scaling`.
- [x] Элитный модификатор: размер ×1.4, 4 глаза, кайма `#B07CFF` 2pt + G1, HP ×5, урон ×1.5, скорость ×1.1, иммунитет к оглушению, искры ×5 + гарант. топливо, сгорание фиолетово-белое, цифра ×1.8.

### 2. Общая FSM `Enemy.gd` (E1–E8)
- [x] E1 СПАВН (600 мс): глаза `scaleY 0→1` (`ease.settle`), тело проявляется в тумане 400 мс; урона и движения нет.
- [x] E2 ОХОТА: движение архетипа к игроку, глаза смотрят на игрока; шлейф-капли `#06070C` 3–6/с; дальше 2 экранов 4 с → DESPAWN.
- [x] E3 ПРОЯВЛЕНИЕ (150 мс): вошёл в `LightArea` игрока → rim 0→1, squash 0.9 / stretch 1.1 → 1, глаза сужаются, «шшш».
- [x] E4 ГОРЕНИЕ: DoT тиками 250 мс (от `LightDamageSystem`), трещины = `1 − HP%`, скорость −15%; вышел из света → E2 (трещины остаются).
- [x] E5 ТЕЛЕГРАФ (400–700 мс по архетипу, **не сокращается** на любой сложности): глаза белые с красным ореолом, тело сжимается 8%, метка на полу.
- [x] E6 КОНТАКТ: `PlayerLight.apply_damage(contact_damage_pct)`, отскок 24pt (`ease.settle`, 200 мс), красная вспышка обводки 120 мс, КД касания 500 мс на этого врага.
- [x] E7 СГОРАНИЕ (480 мс): hit-stop 30 мс (только L/XL), раскал `#FFF1D0` 80 мс, хлопок на 8–12 угольков, остаточное свечение 200 мс, «пшш» (высота зависит от размера).
- [x] E8 ДРОП: искры (пул) с отскоком, пепел-декаль `#7A7064` 35% на 2 с, возврат врага в пул.
- [x] DESPAWN: только вне кадра, глаза закрываются 200 мс; враг никогда не исчезает на глазах у игрока.
- [x] STUN (Пульсар / Взрыв Света, 600 мс): отбрасывание по радиусу, глаза-чёрточки, вращение ±15°.
- [x] Моргание глаз раз в 3–5 с случайно (вне телеграфа).
- [x] Метод `reset(def: EnemyDef, pos: Vector2, elite: bool)` для пула — вместо `_ready`-инициализации.
- [x] Хуки для навыков (task_4): `apply_slow(pct, source)` (берётся максимум из источников), `apply_freeze(seconds)`, `apply_knockback(dir, force)`, `apply_burn_after_exit(seconds)` (Инферно).

### 3. Атаки архетипов
- [x] **Шёпот:** только касание, прямое преследование + разделение стаи (дистанция 0.6 размера) через `SeparationGrid` (проверка 1 раз в 2 кадра). При смерти лопается «пузырём» (6 угольков).
- [x] **Жнец:** подкрадывается до 200pt, замирает, телеграф 500 мс — метка **ЛИНИЯ** (ширина = хитбокс, заливка бежит к концу), рывок 180pt по прямой, чёрный след 300 мс, КД 3 с.
- [x] **Пожиратель:** медленно идёт, толкает мелких, отбрасывание от Пульсара ослаблено на 70%; телеграф 700 мс «вдох» +12% и метка **КРУГ** 1.5 размера; смерть — раскол по трещинам + 3 Шёпота через 300 мс.
- [x] **Гаситель:** держит дистанцию на краю света; аура 3× размера «съедает» 30% света игрока (модификатор радиуса, не урон) и тушит топливо на полу; метка **ЗОНА ТЬМЫ** (пунктир `#B07CFF`). Появление: low-pass музыки, фиолетовая дымка по краям, гул 1.2 с. Взрыв Света снимает 25% HP и выключает ауру на 3 с. Смерть: hit-stop 60 мс, вспышка XL, гарант. топливо ×2 + 40 искр, свет игрока на 1 с расширяется до края экрана, тряска 4pt, сундук забега (шанс по `chests.json.run`).
- [ ] **Плакальщик*:** держится в 260pt, раз в 2.5 с капля 140 pt/с; телеграф 600 мс, метка **ПРИЦЕЛ** — выстрел в точку, где был игрок в момент 100%; капля сгорает за 0.3 с в свете.
- [x] Лимит 6 активных меток: остальные атаки ждут слота; смерть во время телеграфа гасит метку за 120 мс.

### 4. Визуальные законы (шейдеры)
- [x] Тело `#0A0B12`, центр `#03040A`, всегда темнее пола; край размыт 1–2pt.
- [x] Глаза `#FF3B5C`, эмиссия ×2.5, **unshaded** — видны сквозь тьму на любом расстоянии; блик `#FFE0E6` 25% диаметра.
- [ ] Rim-свет только от `PointLight2D` игрока (normal map + rim-шейдер), толщина 3–6pt, цвет = цвет скина: Базовый `#FFB547`, Призрачный `#BFD4FF`, Плазменный `#E68CFF`, Лунный `#D8D0FF`; для красных/розовых скинов — смещение к `#FFD0D8`.
- [ ] Трещины: dissolve по шуму, порог `1 − HP%`, край `#FFC86B` с эмиссией — это и есть HP-бар врага (UI-полоски нет).
- [x] Число глаз = опасность: 2 обычный, 3 тяжёлый, 4 + фиолетовая кайма — элита.
- [x] Никакого `modulate` в тёплые цвета (удалить legacy-мигание красным/жёлтым).

### 5. Урон светом `LightDamageSystem`
- [x] Единая система: раз в 250 мс (200 мс на Ауре ур.3+) проходит по врагам в `LightArea` и наносит `aura_dps × tick`; модификаторы из навыков через `StatBlock`/`RunContext`.
- [x] Накопление для цифр урона: у каждого врага аккумулятор, выпуск раз в **0.4 с** (GDD 3.4, DS); стиль: `NORMAL` кремовый `#FFF1D0`, `BIG_TICK` золотой `#FFD166` (тик ≥ 3× базового), `LETHAL` красный `#FF3B5C` ×1.5 с «!» (для Шёпота добивание — кремовое без «!»). Эмит `EventBus.damage_dealt`.
- [x] Плазменный Огонёк: касание мгновенно сжигает врага (элита −40% HP, Гаситель −15%) — флаг в `StatBlock`.
- [x] Инферно: враги, вышедшие из света, горят ещё 2 с.

### 6. Директор волн `WaveDirector` + `configs/waves.json`
- [x] Петля ~90 с: **Расслабление 45 с** (Шёпоты группами 6–12, много искр, туман редкий) → **Напряжение 30 с** (засады, Жнецы, Пожиратели, элита/Гаситель, мало топлива, туман +30%, ударные) → **Награда 15 с** (спавн стоп на 5 с, бочки с Топливом на маркерах чанков, выжившие отступают во тьму, аккорд). Эмит `wave_phase_changed`.
- [x] Таймлайн 10 минут — плотности по 7 отрезкам (0–1:30 … 9–10) из Enemy DS §05; элита 1/волна с 3:00, 2/волна с 7:30; Гаситель на 5:00, 8:00 и финал; 9:00–10:00 — непрерывное напряжение без фазы награды.
- [x] Засада (напряжение): кольцом открываются 12–20 пар глаз (сначала только глаза, 800 мс), затем кольцо сжимается.
- [x] Лимиты: всего 150 активных; Шёпот 120 · Жнец 8 · Плакальщик 4 · Пожиратель 4 · элита 2 · Гаситель 1. При превышении — спавн только после деспавна дальних.
- [x] Солнечный Огонёк: спавн +50% (множитель директора из `StatBlock`/скина).

### 7. Правила спавна `SpawnRing`
- [x] Кольцо на 1.2 экрана от игрока, **никогда в кадре и в свете**.
- [x] Не больше 40% спавна с одной стороны (гистограмма по 8 секторам).
- [x] Не в стене чанка (проверка `PhysicsDirectSpaceState2D.intersect_point` по слою `world`).
- [x] Вес по направлению движения игрока ×1.5.
- [x] Все случайности — `RunContext.rng`.

### 8. Пулы и производительность (Enemy DS §09)
- [x] Пулы: Шёпот 160, остальные по 16, угольки 400, искры 300, метки 6, цифры 40. Прогрев в `RunDirector.start()`; **никаких `instantiate` в бою**.
- [ ] LOD вне света: «глаза + плоский силуэт» — без normal map, без шлейфа, анимация 6 fps (~70% врагов).
- [ ] Шёпоты рендерятся через `MultiMeshInstance2D` (≤ 3 draw call на архетип); логика — на лёгких объектах без `CharacterBody2D` (перемещение вручную + `SeparationGrid`), коллизия с игроком — по дистанции.
- [ ] Бюджет: враги ≤ 5 мс CPU на Redmi 9 при 150 активных — замер `Performance.get_monitor` + собственный таймер в debug-оверлее.

### 9. Анимации (Enemy DS §08)
- [ ] Покадрово: только `idle/move`, `telegraph`, `attack` (12 fps; атака 20 fps). Остальное — общие шейдеры и твины (`eyes_open`, `blink`, `reveal_flinch`, `hit_recoil`, `stun`, `death`).
- [ ] Именование: `enemy_{id}_{clip}_{nn}.png`, `enemy_{id}_n.png`, `enemy_{id}_mask.png` (R — глаза, G — трещины); исходник в 2× (S 72, M 128, L 224, XL 320px).
- [ ] Варианты по главам: только фактура нижней трети и остаток после смерти (лужа / листья / окалина); глаза, силуэт и число глаз не меняются.
