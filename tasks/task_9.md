# Task 9 · Тестирование на iOS-симуляторе (V1, D19)

Статус: **черновик для обсуждения** — объём и порядок работ определяются после ответов на вопросы ниже.

## Контекст

- V1 выходит только на iOS 17+ (D19). Эталон производительности — iPhone XR.
- Инструменты: MCP `ios-simulator` (установка, скриншоты, тапы, описание UI, запись видео), Xcode 26.2 на машине, шаблон экспорта `ios.zip` для Godot 4.7.2 установлен.
- Правила визуальной проверки — `docs/TESTING.md` (скриншот после старта, safe area и Dynamic Island, тап по центрам кнопок, повторный скриншот, логи при крэше).
- Уже проверено: игра на Android-эмуляторе (S01 → S03 → S02 → забег); рендеры всех экранов в редакторе.

## Что нужно сделать (предварительно)

1. Экспорт Xcode-проекта из Godot и сборка под **симулятор** (arm64 / x86_64 simulator slice) без подписи.
2. Нативные плагины в iOS-сборке: GodotApplePlugins (StoreKit 2, Game Center), godot-x/firebase, обёртка Appodeal для iOS (ещё не написана) — что подключаем на этапе симулятора, а что заглушками.
3. Прогон экранов S01–S17 по `docs/TESTING.md` на нескольких моделях симулятора; фиксация найденного.
4. Проверка сценариев: первый запуск, Дар дня, забег до конца и смерть, воскрешение, левел-апы, Маяк и кат-сцены, экипировка и сундуки, магазин (StoreKit-конфигурация для песочницы).
5. Производительность на симуляторе (ориентировочно) и план замера на реальном iPhone XR.
6. Автоматизация: скрипт «собрать → установить → запустить → скриншоты» для повторных прогонов.

## Вопросы к обсуждению

1. **Модели симуляторов:** какой набор — например, iPhone SE (3rd gen, маленький экран без выреза), iPhone 15 / 16 (Dynamic Island), iPhone 16 Pro Max (большой)? Нужен ли iPad (игра портретная 390×844)?
2. **Плагины на симуляторе:** подключаем GodotApplePlugins и godot-x/firebase сразу, или сначала «чистая» сборка с моками (быстрее найти проблемы UI/рендера), а плагины — вторым шагом?
3. **Покупки:** проверяем через StoreKit Configuration File в Xcode (локально, без App Store Connect) или ждём sandbox-аккаунт (A4)?
4. **Appodeal iOS:** писать обёртку (SwiftGodot + ATT) в рамках этой задачи или отдельной, после App Key (A2)?
5. **Firebase:** есть ли уже проект игры (A1)? Без него облако и аналитика на симуляторе остаются выключенными.
6. **Рендерер:** Mobile (Metal через MoltenVK) или Compatibility (OpenGL ES → Metal) для iOS — сравнить на симуляторе и XR?
7. **Критерии «готово»:** какие экраны и сценарии обязательны для закрытия задачи, и что остаётся на реальные устройства и TestFlight?
8. **Подпись и Apple Developer-аккаунт:** есть ли Team ID `BZ7N5TV2NR` в доступе (он в пресете) — нужен для сборки на устройство и TestFlight, не для симулятора.
