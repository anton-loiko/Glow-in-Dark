# Task 6 · Мета-прогрессия: Маяк, Огоньки-классы, Экипировка, сундуки

## Обоснование

Legacy-мета — это `unlocked_level` (счётчик пройденных уровней), `permanent_skills` без UI и потребителей, 4 скина-«цвета» в `StoreManager.SKINS_DB` с ценой в $/искрах, пустые вкладки Gear/Skills. Маяка как объекта нет (Art Direction: «Хаб: 70% экрана — пустота»).

По Meta DS / Gear DS мета — это три стока Искр и один сток Кристаллов:
1. **Маяк** — 100 уровней (1 ур. = 1%), 10 тиров, вехи 25/50/75/100%, перманентные баффы, разблокировка Огоньков-классов и следующей главы; живая диорама, которая «отвоёвывает город у тьмы».
2. **Экипировка** — 4 слота, 5 редкостей, прокачка за Искры по экспоненте, слияние 3 → 1, разбор с возвратом 100%.
3. ~~Сила Огонька~~ — не делаем (D6): статы растут только через Маяк и экипировку.
4. **Сундуки** (Базовый за Искры/▶, Премиум за ◆, сундук забега) — гача с раскрытием редкости.

Архитектура: вся бизнес-логика — в чистых сервисах (`BeaconService`, `GearService`, `ChestService`, `SkinService`) без узлов, тестируемых юнит-тестами; экраны только вызывают их API и слушают `EventBus`. Любое списание валюты + изменение состояния — **одна транзакция** через `GameManager.spend` (task_1).
