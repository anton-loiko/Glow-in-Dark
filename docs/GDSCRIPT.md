# Правила GDScript для проекта Cascade

- Всегда используй строгую типизацию для переменных (например, `var speed: float = 200.0`).
- Избегай использования `get_node()` по строковым путям, используй `@export` переменные или `%UniqueName` для доступа к узлам.
- Всегда отключай `_process` и `_physics_process`, если узел использует их только для инициализации.
