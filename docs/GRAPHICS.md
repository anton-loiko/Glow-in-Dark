# Графический пайплайн проекта Glow in the Dark

Этот документ описывает, как нейросеть должна создавать визуальную часть игры. Стиль — **Hi-Res 2D + 2.5D-освещение** («Биолюминесцентный нуар», Art Direction Reboot). Пиксель-арт в игре не используется. Истина по цветам, размерам и формам — дизайн-системы в `docs/design/*.pdf`.

Базовый вьюпорт — **390×844 pt**. Все размеры в дизайн-системах указаны в pt этого вьюпорта.

## 1. Растровая графика мира (MCP-сервер: Aseprite)

**Что рисуется растром:**

- Огонёк, враги, боссы.
- Окружение: плитка пола чанков, пропсы, биолюминесценция.
- Маяк (постамент, кристалл, диорама Хаба), сундуки, предметы экипировки.
- Текстуры для VFX и частиц (угольки, пепел, искры, капли).

**Правила:**

- Мягкие рисованные формы в высоком разрешении, без пиксельной сетки. Исходник — **2× от экранного размера** (например, враг S — 72px для 36pt, герой — ≈170px для 85pt).
- У каждого освещаемого спрайта есть **normal map** (`<name>_n.png`). В Godot спрайт собирается в `CanvasTexture` (diffuse + normal).
- Маски для шейдеров — отдельным файлом `<name>_mask.png` (например, у врагов R — глаза, G — трещины).
- Фильтрация текстур — **Linear** (не Nearest), mipmaps — по необходимости для мира, выключены для UI.
- Анимации экспортируются горизонтальным спрайт-листом (кадры слева направо). Покадрово рисуется только то, что нельзя сделать шейдером или твином.
- Цветовые законы: тепло (янтарь) — жизнь и награда; красный `#FF3B5C` — только угроза (глаза врагов); голубой — только хард-валюта. Тело врагов темнее тьмы, окружение не ярче 60% яркости врагов в свете и без красного/янтарного.
- Тест силуэта: иконки навыков сначала рисуются мастером на сетке 16×16 (проверка читаемости в грейскейле), финал — hi-res 128px. Это единственное место, где используется сетка 16×16, и в игру мастер не попадает.
- Формат — `.png`. Именование: `enemy_whisper_move_01.png`, `enemy_whisper_n.png`, `hero_idle_01.png` и т.п.

## 2. Векторная графика (MCP-сервер: Inkscape)

**Что рисуется вектором:**

- UI: панели, кнопки, рамки, фоны карточек.
- Иконки HUD и интерфейса (валюты, вкладки, навыки в UI, слоты).
- Логотип, знак, иконка приложения, сплэш.

**Правила:**

- Сохраняй исходники в `.svg`.
- Иконки на сетке 24pt: мягкие формы, заливка + внутренний тёплый блик, **без контура**.
- Делай цвета базовыми (белый или серый), чтобы программист перекрашивал иконку через `modulate` цветом смыслового токена из дизайн-системы.
- Вместо теней — свечение (glow G1/G2/G3). Чёрных drop-shadow нет.
- Пиксельные шрифты не используются. Шрифты: Unbounded, Manrope, JetBrains Mono.
