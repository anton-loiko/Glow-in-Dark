# UI-ревью S01–S17 против дизайн-систем

Дата: 2026-09-25. Метод: рендер всех экранов 390 × 844 (RU), side-by-side с артбордами из `docs/design/*.pdf`
(Design System §03, Meta DS S02 v2, Gear DS S12 v2). Приоритет источников — как в CLAUDE.md.

## Системные находки (исправлены)

| # | Что было | Что стало |
|---|---|---|
| 1 | Primary / Crystal — плоская заливка | `ButtonFace`: градиент 300 → 500 → 700, цоколь 4pt, мягкое свечение G2, блик 1pt; нажатие — цоколь 0, +4pt |
| 2 | Свечения — стопка полупрозрачных кругов (видимые кольца) | Гладкий радиальный градиент (`HeroGlyph.halo_texture()`): Огонёк, Ember, хаб, S12, S10, S17 |
| 3 | Экраны шире 390pt (S10 стартер-пак, S13 «Цифры урона») — контент обрезан справа | Перенос заголовка, компонент `Segmented` (DS §02); тест `tests/ui/test_screen_width.gd` |
| 4 | UI-Огонёк процедурный (пиксельный вид) | Слои из бренд-пака: тело красится цветом скина, ядро и лицо — без окраски |
| 5 | Подписи таб-бара — mono 10, «Навыки» слипались с «Экипировкой» | Manrope 12 (DS §02 TAB BAR) |
| 6 | Сплэш мелькал ~60 мс: таймер 1.2 с «проматывался» огромной delta первых кадров | Ожидание по реальному времени (`Time.get_ticks_msec`) |
| 7 | На десктопе нет безопасных зон — превью не совпадали с артбордами | `SafeAreaContainer` вне iOS/Android подставляет 44 / 34pt |
| 8 | Disabled у кнопок S06 — серая заливка | Пунктир + причина («Нужно 50 ✦»), по правилу 5 DS |

## По экранам (исправлены)

- **S01** — знак: Огонёк с лицом (`splash_mark.png`), подпись приглушённая, интерлиньяж 34/38, свечение без ступенек.
- **S02 (Meta DS v2)** — янтарная метка главы + «Маяк» display; «Внести Искры» в две строки (действие + «1 ур. · N ✦ · удерживай…»), состояния HOLDING/TIER-READY/DISABLED с подстрокой, скруглённый пунктир; процент — Unbounded 18; строка «На N%: бафф · скин» с иконкой скина в его цвете; «Дар дня» — сундук-объект диорамы с красной точкой.
- **S03** — будущие дни пунктиром (правило 6), иконки наград, день 7 — широкая эпическая ячейка с сундуком, «до сброса N ч» всегда.
- **S04** — миниатюры биомов, бейдж «СЕЙЧАС», цель и 5 отметок, закрытые — пунктир + замок, «Рекорд 00:00» скрыт.
- **S05** — уровень в кольце spark, иконка Искры в пилюле, таймер строго по центру, пауза — иконка; пол приглушён (Art Direction: «приглушённая насыщенность»).
- **S06** — Unbounded в заголовке и картах, пилюля «Собрано» с 6 слотами по категориям, кнопки DS (Secondary / ▶ / Crystal), строки через `tr()` (раньше не переводились).
- **S07** — карточки навыков (иконка в рамке категории, «N / 5»), тумблеры DS в карточках, непрозрачный фон.
- **S08** — тёмный фон, остывший Огонёк в янтарном кольце, цифра под кольцом, «лучший забег в этой главе», глаза во тьме.
- **S09** — радиальный тёплый свет, полупрозрачные карточки статистики, «★ рекорд», горка искр (×3 утраивает её за 600 мс), инверсная Primary через `ButtonFace.INVERTED`.
- **S10** — таймер оффера — красный бейдж.
- **S12 (Gear DS v2)** — фильтр — Segmented, подписи ленты скинов с многоточием, «надет» — контур цветом скина, закрытые — скруглённый пунктир.
- **S13** — Segmented, «Game Center» по умолчанию (D19).
- **S17** — открытый сундук терял альфу (серый квадрат за картой): спрайт — дочерний `TextureRect`, шов — верхний слой.
